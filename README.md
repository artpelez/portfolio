## 🌐 Publicación en GitHub Pages (En 1 Minuto)

1. Sube el contenido de esta carpeta a tu repositorio en GitHub.
2. En GitHub, entra en **Settings** ➔ **Pages**.
3. En la sección **Build and deployment / Branch**, selecciona la rama **`main`** (o `master`) y carpeta **`/(root)`**.
4. Pulsa **Save**. En un minuto estará publicado en:  
   `https://tu-usuario.github.io/tu-repositorio/`

---

## 🖨️ Cómo generar el CV en PDF desde `cv.html`

1. Abre `cv.html` con cualquier navegador (Google Chrome o Edge recomendados).
2. Pulsa en el botón flotante **"Guardar en PDF / Imprimir"** (o `Ctrl + P`).
3. En la ventana de impresión:
   * **Destino:** *Guardar como PDF*.
   * **Páginas:** *1* (calibrado para 1 página A4 exacta).
   * **Márgenes:** *Ninguno* o *Mínimo*.
   * **Opciones:** Marcar *Gráficos de fondo*.
4. Pulsa **Guardar**.
